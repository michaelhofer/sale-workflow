1.  Enable Sales \> Configuration \> Settings \> Discounts
2.  Configure a pricelist rule with Discount computation and the three
    discounts
3.  Create a sale order and select the configured pricelist
4.  Add a product in the sale order, matching a rule of the configured
    pricelist
5.  Check that the three discounts defined on the pricelist rule
    populate the three discounts of the sale order line
